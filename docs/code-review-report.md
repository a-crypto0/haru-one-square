## 구조 감사

- `public/`, 아이콘, `vercel.json`, 빌드 스크립트를 `frontend-ui` v1.1.0에 배정했다.
- `frontend-ui`와 모듈 인덱스 버전이 1.1.0으로 일치한다.
- 서비스 워커는 same-origin GET 정적 파일만 처리하고 외부 Supabase 요청을 가로채지 않는다.
- SPA rewrite, 서비스 워커 재검증 헤더, 해시 번들 장기 캐시가 분리되어 있다.
- 클라이언트 비밀키·직접 HTML 주입·타입 우회가 없다.
- `package.json`과 `package-lock.json`의 웹 의존성·Node 엔진이 일치한다.

## 회부 후 해결

1. 서비스 워커 등록 Promise의 실패 처리가 없던 문제 → 오류를 안전하게 종료하도록 처리.
2. 로컬 보안 컨텍스트에서 자동 PWA 등록을 검증할 수 없던 문제 → localhost·127.0.0.1을 허용하고 개발용 번들은 캐시에서 제외.
