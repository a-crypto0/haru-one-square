# 리뷰 메모

## Important

1. 실제 기기 간 지원자 공유
   - 현재 화면과 로컬 서비스, Supabase 스키마·RLS는 준비됐지만 `appServices`는 로컬 구현만 사용한다.
   - 초대 코드 또는 계정 주소 중 연결 방식을 확정한 뒤 원격 어댑터와 지원자 수락 흐름을 구현해야 한다.

2. 기기 모듈 설치
   - `expo-notifications`, `expo-speech`, `expo-image-picker`는 이번 PWA 배포 준비 범위에 포함하지 않아 설치하지 않았다.
   - 설치 전 알림·읽어주기는 안전한 no-op이고 약 사진 버튼은 시연용 경로를 사용한다.

3. 오늘만 바꾼 알림 시간
   - 당일 override는 저장되지만 반복 알림 API가 기본 일정 기준이라 당일 변경 시간으로 별도 예약되지 않는다.
   - 날짜가 포함된 1회 알림 계약을 추가한 뒤 기본 반복 알림과 별도 식별자로 관리해야 한다.

4. 실제 사용자 검증
   - 자동 E2E와 실기기 검증이 없어 `양치 완료 → 오늘만 시간 변경 → 지난주 기록 → 되돌리기` 동선을 실제 사용자와 확인해야 한다.

## Dependency note

- `npm audit`은 Expo 빌드 도구가 사용하는 `uuid` 경로를 포함해 중간 수준 항목 21개를 보고했다. 높음·치명적 항목은 0개다.
- 현재 `uuid` 경로에는 호환 가능한 자동 수정안이 없어 `npm audit fix --force`를 실행하지 않았다. Expo SDK가 호환 버전을 올리면 함께 갱신한다.
