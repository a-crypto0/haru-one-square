# 디자인명세

작성일: 2026-08-27
상태: 최종 확정
디자인 출처: 직접 설계(B경로) — 마이루틴의 정보 구조와 파스텔 루틴 보드 감성을 성인형으로 재해석
원본: `docs/plan.md`

## 1. 디자인 목표

성인 발달장애인이 설명 없이도 `오늘 할 일 확인 → 직접 체크 → 필요하면 수정 → 지난 기록 확인`을 수행할 수 있게 한다.

첨부 이미지에서는 따뜻한 바탕, 굵은 제목, 둥근 카드, 저채도 파스텔, 정돈된 격자만 차용한다. 이미지 안의 문구·기능·점수·연속 달성·완료율은 구현 요구로 해석하지 않는다.

### UX 원칙

1. **성인으로 존중한다:** 아기 동물, 과장된 칭찬, 불꽃, 별점, 반말을 쓰지 않는다.
2. **한 번에 한 결정:** 쉬운 모드의 입력은 한 화면에 질문 하나만 보여준다.
3. **사용자가 주인이다:** 지원자가 만든 일정도 작성자를 표시하고 당사자가 시간 변경·숨김·도움 요청을 할 수 있다.
4. **실수는 되돌릴 수 있다:** 반복 범위, 약 관련 변경, 삭제, 공유 중단은 확인하고 저장 뒤 되돌리기를 제공한다.
5. **빈칸은 실패가 아니다:** `완료 / 기록 없음 / 예정 없음`을 색뿐 아니라 모양과 글자로 함께 표시한다.

### 2.2 글꼴·크기

- 글꼴: `Pretendard` 우선, 기기 한국어 시스템 고딕 대체
- 큰 제목: 30/38, 800
- 화면 제목: 24/32, 800
- 구역 제목: 20/28, 700
- 일반 모드 본문: 16/24, 500
- 쉬운 모드 본문: 19/30, 600
- 보조 문구: 14/22, 500(쉬운 모드 16/24)
- 숫자 입력: 32/40, 700, 고정폭 숫자 사용
- 핵심 안내는 한 문장 20자 안팎, 한 문장에 행동 하나만 쓴다.

### 2.3 간격·모서리·그림자

- 간격: 4, 8, 16, 24, 32의 8px 계열
- 카드 안쪽 여백: 일반 16, 쉬운 모드 20
- 카드 간격: 12~16
- 카드 모서리: 24
- 입력칸·버튼 모서리: 18
- 상태 칩 모서리: 999
- 카드 그림자: 1단계만 사용(얕고 넓은 그림자), 중첩 카드에는 그림자 금지
- 주요 버튼 높이: 일반 48 이상, 쉬운 모드 56 이상
- 모든 터치 영역: 최소 44×44, 권장 48×48

### 2.4 아이콘·이미지·움직임

- 아이콘은 둥근 선형 스타일 한 종류만 사용하고 반드시 짧은 글자와 함께 둔다.
- 할 일 색은 세이지·라벤더·스카이·버터의 연한 배경 토큰 중 선택한다. 핵심 의미를 색으로만 전달하지 않는다.
- 약 사진은 64×64 이상, 모서리 16, 대체 글자 `등록한 약 사진`을 제공한다.
- 화면당 장식 일러스트는 최대 1개이며 핵심 행동보다 먼저 보이지 않는다.
- 화면 전환 180ms, 체크 피드백 160ms. 흔들기·폭죽·자동 재생 없음.
- 기기의 `움직임 줄이기` 설정을 따르면 상태가 즉시 바뀌고 애니메이션을 생략한다.

### 2.5 앱 셸·반응형

- 모바일(~767): 한 열, 고정 하단 메뉴 `오늘 / 기록 / 함께 / 설정`, 저장 버튼은 안전영역 위에 고정
- 태블릿(768~1023): 72px 왼쪽 메뉴, 중심 콘텐츠 최대 720px, 기록 화면은 할 일 목록과 격자를 나란히 배치
- PC(1024~): 240px 왼쪽 메뉴, 콘텐츠 최대 1120px, `함께 관리`는 일정과 변경 내역을 2열로 표시
- 모든 크기에서 정보·문구·기능 순서를 유지한다. 작은 격자는 확대가 아니라 가로 스크롤 또는 할 일 한 개 보기로 전환한다.

## 3. 쉬운 모드와 일반 모드

기능과 저장 데이터는 같고 밀도와 입력 방식만 다르다.

| 영역 | 쉬운 모드 | 일반 모드 |
|---|---|---|
| 오늘 | 시간대별 큰 카드, 한 카드 한 행동 | 시간순 목록과 작은 보조정보 |
| 글자·버튼 | 본문 19px, 주요 버튼 56px | 본문 16px, 주요 버튼 48px 이상 |
| 할 일 편집 | 이름→아이콘→시간→반복→확인 단계 | 모든 입력을 한 스크롤에 표시 |
| 순서 변경 | `위로 / 아래로` 버튼 | 이동 손잡이 + 위/아래 대체 버튼 |
| 주간 기록 | 선택한 할 일 한 개의 큰 7칸 | 여러 할 일을 행으로 표시 |
| 월간 기록 | 선택한 할 일 달력 한 개 | 할 일별 작은 달력 카드를 세로 표시 |
| 변경 내역 | 쉬운 문장 카드 | 변경 전후를 한 행에 표시 |
| 읽어주기 | 상단에 `읽어주기` 글자 버튼 항상 표시 | 상단 도구 영역에 아이콘+글자 |

## 5. 텍스트 와이어프레임

### S001 처음 설정 — 쉬운 모드

```text
[2 / 3]

화면을 어떻게 볼까요?                       [읽어주기]

[  쉬운 모드  ]
큰 글자와 큰 버튼으로 한 가지씩 보여줘요.

[  일반 모드  ]
여러 내용을 한눈에 보여줘요.

                                      [다음]
```

1단계 계정, 2단계 표시 모드, 3단계 읽어주기 순서로 진행한다. 완료 화면에는 `[지원자 연결하기] [나중에]`를 함께 보여주며, 연결하기를 누르면 S007로 이동한다. 지원자 연결을 건너뛰어도 앱을 사용할 수 있다.

### S004 할 일 추가·수정

```text
[뒤로]  할 일 바꾸기                     [읽어주기]

이름      [ 양치하기                         ]
그림      [칫솔] [걷기] [샤워] [약] [더 보기]
색        [세이지✓] [라벤더] [스카이] [버터]
시간      [20:00]
반복      [월][화][수][목][금][토][일]
알림      [켜짐]

약 복용을 고르면:
약 사진   [사진 추가/바꾸기]
[안내] 앱의 알림만 바뀌어요.
       복용 방법은 의사·약사의 안내를 따라요.

                                      [저장]
──────────────────────────────────────────
[이 할 일 삭제]
```

반복 중인 할 일을 수정하면 저장 전에 `오늘만 바꿀까요? / 오늘부터 계속 바꿀까요?`를 묻는다. 약 관련 변경·삭제는 약 이름을 포함한 안전 확인을 한 번 더 거친다.

- 새 할 일: 쉬운 모드는 `이름→그림·색→시간→반복·알림→확인` 단계로 진행한다.
- 기존 할 일: 먼저 `무엇을 바꿀까요?`에서 `이름·그림 / 시간 / 반복 요일 / 알림 / 색` 중 하나를 고르고 해당 항목만 연다.
- 시간·반복 변경: 값을 고치기 전에 `오늘만 / 오늘부터 계속`을 선택한다.
- 약 시간 변경: `약 알림 시간`이라고 명확히 쓰고, 반복 범위·새 시간·안전 안내를 한 확인 화면에 합친다. 저장 뒤 `지원자에게도 변경 내용이 보여요`를 알린다.

## 9. 기획-디자인 대조

- F001~F010이 화면·컴포넌트 또는 PWA 배포 셸에 매핑되어 있다.
- 용돈 기록 화면·입력칸은 만들지 않는다.
- 성장 정원·점수·완료율·연속 기록·순위·캐릭터 화면은 만들지 않는다.
- 첨부 이미지의 작은 월간 통계 카드는 모바일 홈에 넣지 않고 S006 상세 화면에만 파생했다.
- 지원자용 별도 대시보드를 만들지 않고 S003·S004·S007 구조를 권한에 따라 재사용한다.

## 14. v1.2 마이루틴 계열 시각 개편

### 14.1 참고 범위와 독자성

- 참고: 마이루틴 공식 소개와 앱스토어 공개 화면의 `주간 날짜 → 시간대 구역 → 이모지 루틴 행 → 체크` 정보 구조.
- 차용: 밝은 크림 배경, 민트 중심색, 버터·라벤더·스카이 파스텔 구역, 작은 주간 날짜 칸, 둥근 루틴 카드와 떠 있는 하단 메뉴.
- 복제하지 않음: 마이루틴 로고·이름·문구·그래픽 자산·배지·스탬프·점수·소셜 화면·고유 아이콘.
- 기존 기능과 데이터 흐름은 바꾸지 않고 시각 위계와 카드 배치만 변경한다.

### 14.2 개편 토큰

- 라이트 배경 `#FFFDF7`, 표면 `#FFFFFF`, 기본 글자 `#26322C`.
- 주색은 선명하지만 눈부시지 않은 민트 그린 `#36B879`, 보조색은 라벤더 `#8572CF`.
- 시간대 배경은 버터 `warning-soft`, 민트 `primary-soft`, 라벤더 `secondary-soft`, 스카이 `info-soft` 네 토큰만 사용한다.
- 카드 모서리는 24, 떠 있는 하단 메뉴와 선택 칩은 pill 모서리를 사용한다.
- 그림자는 카드와 하단 메뉴에만 한 단계로 제한하고 중첩하지 않는다.

### 14.3 오늘 화면

- 상단: `하루한칸` 이름, 오늘 날짜, 부담 없는 한 문장 안내를 배치한다.
- 그 아래 월~일 7칸 주간 스트립을 두고 오늘만 주색 채움+굵은 글자로 표시한다. 날짜 칸은 이동 버튼이 아니라 현재 위치 안내다.
- 오늘 할 일 수와 기록한 수를 숫자로만 보여주며 퍼센트·점수·연속 기록은 만들지 않는다.
- 할 일은 시간 기준 `아침 / 낮 / 저녁 / 시간 미정`으로 나누고 빈 구역은 표시하지 않는다.
- 각 루틴은 이모지, 이름, 시간, 수정, 체크 행동이 한 카드 안에서 한눈에 보인다.
- 약 루틴의 `나중에 / 도움 필요`는 체크 아래의 보조 행동으로 유지한다.

### 14.4 다른 화면

- 내 할 일: 이모지 버블과 파스텔 배경을 사용한 한 줄 카드로 순서·반복·수정을 정리한다.
- 기록: 주간·월간 칸을 모서리 10의 작은 사각형으로 바꾸고 완료 `✓`, 기록 없음 `○`, 예정 없음 `—`을 유지한다.
- 처음 설정: 흰 카드, 3단계 진행 점, 민트 주요 버튼을 사용해 첫 화면부터 같은 제품으로 느껴지게 한다.
- 체중·함께·설정: 기능 구조는 유지하고 공용 토큰·버튼·카드만 같은 시각 체계로 통일한다.
- 모바일은 한 열과 떠 있는 하단 메뉴, 태블릿·PC는 기존 왼쪽 메뉴 구조를 유지한다.

### 14.5 사용자대표 재검토

- 불편: 파스텔과 이모지가 많으면 성인에게 유치하게 느껴질 수 있다. → 캐릭터·칭찬 배지 없이 할 일당 이모지 하나, 시간대당 배경색 하나만 사용한다.
- 불편: 작은 체크 UI가 쉬운 모드에서 누르기 어려울 수 있다. → 실제 누르는 버튼은 최소 48px, 쉬운 모드는 56px을 유지한다.
- 호감: 주간 날짜와 시간대별 묶음 덕분에 `지금 할 일`을 긴 설명 없이 찾을 수 있다. → 오늘 화면의 가장 강한 시각 위계로 반영한다.

## 15. v1.3 고밀도 루틴 보드 개편

사용자가 공개 레퍼런스를 빠른 수정용 베이스로 삼기로 확정했다. 브랜드 자산을 복제하지 않고, 공개 화면에서 관찰되는 정보 배열과 조작 밀도를 `하루한칸`의 기존 기능에 맞춰 재구성한다.

### 15.1 오늘 화면 밀도

- 큰 독립 카드의 연속 대신 `시간대 머리글 + 이어진 루틴 행` 구조를 사용한다.
- 시간대 머리글은 왼쪽에 시간대·심볼, 오른쪽에 완료 수를 표시하고 연한 버터·스카이·라벤더 배경을 사용한다.
- 루틴 행은 `시간/상황 열 → 이모지와 할 일 이름 → 오른쪽 체크 칸`의 3열 구조다.
- 완료 행동은 전체 너비 초록 버튼이 아니라 오른쪽 56px 체크 칸으로 배치한다. 미완료는 빈 원, 완료는 체크와 연한 채움으로 구분한다.
- 수정은 행 오른쪽 위의 독립된 `수정` 또는 더보기형 글자 버튼으로 제공하며 체크 영역과 겹치지 않는다.
- 약 일정의 `나중에 / 도움 필요`와 지원자 작성자 표시는 해당 행 아래의 보조 줄로 유지한다.
- 주간 날짜 띠는 표 상단에 붙여 카드·그림자를 줄이고, 오늘 날짜만 민트 원형 채움으로 표시한다.

### 15.2 관리·기록 화면

- 내 할 일은 개별 그림자 카드 대신 한 표면 안의 이어진 행으로 바꾸고, 이모지·시간·반복·순서·수정을 한 행에 정리한다.
- 기록 화면은 날짜 머리글과 정사각형 기록 칸의 간격을 좁히되 `✓ / ○ / —` 기호와 접근성 문구는 유지한다.
- 하단 메뉴는 흰 표면과 민트 선택 배경을 유지하되 그림자를 약하게 하고 화면 콘텐츠와 시각적으로 분리한다.

### 15.3 독자성과 접근성 경계

- 원 앱의 이름·로고·캐릭터·문구·배지·스탬프·고유 아이콘·소셜 화면은 사용하지 않는다.
- 점수·완료율·연속 기록 등 기존 기획에서 제외한 기능은 추가하지 않는다.
- 시각상 조밀해져도 모든 누르는 영역은 최소 48px, 쉬운 모드는 56px을 유지한다.
- 카드 전체 누르기로 완료시키지 않고 체크와 수정의 접근성 라벨·역할·상태를 각각 제공한다.

### 15.4 T030 완료 기준

- 파일: `TodayScreen`, `TaskCard`, `CompletionControl`, `TaskList`, `PeriodHabitGrid`와 필요한 공용 토큰·문구만 수정한다.
- 모바일 390px에서 가로 넘침 없이 오늘→체크→되돌리기→관리→기록 동선이 동작한다.
- TypeScript 엄격 검사, 웹 export, PWA 오프라인 새로고침을 통과한다.

## 16. v1.4 기록·통계 화면 개편

첨부된 주간·월간 통계 레퍼런스의 표 구조와 파스텔 밀도를 `하루한칸` 기록 화면에 맞춰 재구성한다. 기존 기록 상태와 기간 이동 기능은 유지하고, 통계를 평가나 점수가 아닌 생활 패턴 확인 도구로 표현한다.

### 16.1 상단 기간 전환

- 화면 제목 아래에 `주간 / 월간` 두 칸 세그먼트를 한 줄로 둔다.
- 선택 항목은 민트 채움과 굵은 글자, 미선택 항목은 흰 표면과 테두리로 구분한다.
- 이전·다음 이동은 좌우 48px 버튼으로 제공하고 가운데에는 주간 `YYYY년 M월 · N주`, 월간 `YYYY년 M월`을 표시한다.
- 주간의 개별 날짜 범위 문구는 노출하지 않아 요일 비교에 집중하게 한다.

### 16.2 주간 통계

- 하나의 흰 패널 안에 첫 행 `할 일 / 월 / 화 / 수 / 목 / 금 / 토 / 일`을 고정한다.
- 각 할 일은 이모지와 이름 한 줄, 오른쪽에는 월~일 7개의 정사각형 상태 칸을 배치한다.
- 날짜 숫자는 표시하지 않는다. 완료 `✓`, 기록 없음 `○`, 예정 없음 `—` 기호를 색과 함께 사용한다.
- 할 일 고유 색 토큰을 완료 칸의 연한 배경과 진한 기호에 사용한다.
- 모바일 390px에서 가로 스크롤 없이 7개 요일이 모두 보이며, 쉬운 모드에서도 상태 칸은 읽기 전용이므로 32~36px 밀도를 허용한다.

### 16.3 월간 통계

- 월간은 가로로 긴 전체 표 대신 할 일별 작은 달력 카드를 세로로 나열한다.
- 카드 머리글에 이모지·할 일 이름과 `완료 N회`를 표시한다.
- 달력 머리글은 월~일이며, 날짜 숫자와 상태 기호를 같은 칸에 표시한다.
- 해당 달 바깥 칸은 만들지 않고 월 시작 요일만큼 빈 칸을 두어 실제 달력 위치를 유지한다.
- 퍼센트, 점수, 순위, 연속 기록은 추가하지 않는다.

### 16.4 상태·반응형·접근성

- loading/error/empty 문구는 기존 한국어 상태 컴포넌트를 유지한다.
- 모바일은 한 열, 태블릿은 월간 카드 두 열, PC는 가능한 범위에서 두~세 열로 배치한다.
- 기간 이동과 주간/월간 전환은 최소 48px, 쉬운 모드는 56px 터치 영역을 유지한다.
- 각 상태 칸의 접근성 문구는 `요일 또는 날짜 + 할 일 이름 + 완료/기록 없음/예정 없음` 순서로 제공한다.
- 체중 기록 카드는 기록 통계 아래에 유지하되 통계 패널과 같은 흰 표면·얇은 테두리를 사용한다.

### 16.5 T031 완료 기준

- 파일: `RecordsScreen`, `PeriodHabitGrid`, 필요한 한국어 문구와 문서만 수정한다.
- 주간 화면은 날짜 숫자 없이 월~일 요일 머리글을 표시한다.
- 월간 화면은 할 일별 달력 카드를 표시한다.
- 390px에서 기간 전환, 주간↔월간, 기록 범례, 체중 기록 이동이 가로 넘침 없이 동작한다.

### 16.6 사용자대표 검토

- 불편: 날짜 숫자가 7개 연속되면 어느 요일의 습관인지 다시 계산해야 한다. → 주간 표 머리글을 월~일로 고정하고 날짜 숫자를 제거한다.
- 불편: 31일 전체 표를 가로로 밀어야 하면 모바일에서 할 일 이름과 날짜를 동시에 보기 어렵다. → 월간을 할 일별 7열 달력 카드로 바꾼다.
- 호감: 같은 위치의 요일 칸을 반복해서 보면 생활 패턴을 빠르게 알아볼 수 있다. → 주간 화면의 핵심 위계로 강화한다.
