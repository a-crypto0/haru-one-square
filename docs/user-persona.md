# 사용자 페르소나

## 주 사용자

- 누구: 스마트폰의 기본 조작이 가능하고, 자신의 생활을 직접 관리하고 싶은 성인 발달장애인 A씨
- 이용 방식: 필요에 따라 쉬운 모드 또는 일반 모드를 선택하고, 매일의 할 일은 본인이 직접 추가·수정·완료한다.
- 지원 관계: 지원자 1명과 일정을 공유하지만, 지원자의 역할은 대신 결정하는 관리자가 아니라 선택한 도움 제공자다.
- 현재 해결책: 확인 필요. 종이 기록, 메신저 알림, 보호자의 말로 하는 안내 등 실제 방식을 사용자 조사에서 확인한다.
- 불편·절박함: 복잡한 입력, 유아적인 말투, 누가 만든 일정인지 알 수 없는 화면은 자율감을 떨어뜨린다.
- "이거다" 하는 순간: 앱을 켠 뒤 도움 없이 다음 할 일을 이해하고, 직접 체크하거나 일정을 고친 뒤 기록이 남은 것을 확인한다.

## 대상 아님

- 아동 전용 캐릭터·말투가 필요한 사용자
- 복용량 변경이나 치료 판단을 원하는 사용자
- 여러 기관과 다수 이용자를 관리하는 시설용 대시보드 사용자
- 첫 버전에서 용돈 지출을 기록하려는 사용자

## 검증 시 주의

- 발달장애 진단명으로 읽기·숫자·색·소리에 대한 능력을 단정하지 않는다.
- 지원자가 대신 누르지 않은 상태에서 당사자가 스스로 과업을 완료하는지 관찰한다.
- 아이콘만 보여주지 말고 항상 쉬운 글자를 함께 제공한 상태로 검증한다.
