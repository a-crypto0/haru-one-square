# frontend-ui 모듈

- 버전: 1.2.3
- 상태: 완료
- 담당 작업: T016~T031
- 목적: 성인에게 맞춘 파스텔 루틴 플래너의 9개 화면과 17개 공통 컴포넌트를 쉬운·일반 모드와 설치형 PWA로 제공한다.

## 담당 파일

- `App.tsx`
- `src/frontend/screens/`: 처음 설정, 오늘, 할 일 관리·편집, 체중, 기록, 함께 관리, 변경 내역, 설정의 9개 화면
- `src/frontend/components/`: 디자인 명세 C001~C017과 공통 상태·버튼 부품
- `src/frontend/hooks/`: 서비스 계약을 화면 상태로 연결하는 10개 훅
- `src/frontend/theme/`: 라이트·다크 색상, 쉬운·일반 모드 글자·터치·반응형 토큰
- `src/frontend/types.ts`, `src/frontend/utils/date.ts`
- `src/content/ko/copy.ts`
- `public/`: HTML 셸, manifest, 서비스 워커, 오프라인 안내, 설치 아이콘
- `assets/icon.png`, `assets/app-icon.svg`
- `app.json`, `vercel.json`, `package.json`

## 외부 연결

- 데이터 작업은 `src/service/contracts.ts`의 타입 계약과 `src/service/index.ts`의 `appServices`만 사용하며 `src/db/`를 직접 참조하지 않는다.
- 날짜는 기기 현지 `YYYY-MM-DD`, 반복 요일은 서비스 계약과 동일한 `0(일)~6(토)`로 전달한다.
- `오늘만` 수정은 당일 시간·표시 override만, `오늘부터 계속`은 할 일·반복 정의 변경만 서비스에 전달한다.
- 모든 색상은 `src/frontend/theme/tokens.ts`에서 가져온다.
- 모바일을 우선하고 768px, 1024px 경계에서 밀도와 내비게이션만 조정한다.
- 공통 버튼은 최소 48px, 쉬운 모드는 56px이며 역할·라벨·선택 상태를 접근성 속성으로 제공한다.
- 기기 알림·읽어주기·약 사진 접근은 프런트엔드가 직접 구현하지 않고 `appServices` 인터페이스를 호출한다.
- PWA 서비스 워커는 같은 출처의 정적 파일만 캐시하고 외부 API 요청은 캐시하지 않는다.
- 모바일 화면의 바깥 여백은 폭 100% 컨테이너 안쪽에 두어 390px에서도 가로 넘침이 생기지 않는다.
