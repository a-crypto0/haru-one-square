# db-data 모듈

- 버전: 1.0.0
- 상태: 완료
- 담당 작업: T001~T007
- 목적: 할 일 정의와 날짜별 기록을 분리하고, 체중·복약·지원자 공유 데이터를 RLS로 보호한다.

## 담당 파일

- `src/db/types.ts`
- `src/db/client.ts`
- `supabase/migrations/*_initial_schema.sql`
- `supabase/seed.sql`

## 외부 연결

- 서비스 레이어에 도메인 타입을 제공한다.
- 앱 프런트엔드는 이 모듈을 직접 호출하지 않는다.
- 공개 스키마의 모든 앱 테이블은 RLS를 사용하고, 인증 사용자는 자신의 데이터 또는 명시적으로 공유된 데이터만 접근한다.
